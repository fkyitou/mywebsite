# منابع پژوهش

منابع ده مقاله‌ی نخست، سازوکار بلاگفا و روش کار در [گزارش پژوهش و منابع](docs/04-sources-report.md) آمده است و این‌جا تکرار نمی‌شود. این صفحه منابعی را می‌گوید که کیت ۹ به آن‌ها تکیه دارد. هیچ منبع، عدد یا نقل‌قولی ساخته نشده است. آخرین به‌روزرسانی: ۲۳ آبان ۱۴۰۵ (۱۴ نوامبر ۲۰۲۶).

## مقاله‌ی ۱۱: ویدیوسازهای هوش مصنوعی

`posts/11-video.html`، ۱۲ منبع در پایان مقاله. هر عدد روی صفحه‌ی رسمی خود سازنده خوانده و ۱۲ نوامبر ۲۰۲۶ دوباره بررسی شد؛ همه‌ی عددهای پیش‌نویس درست ماندند. نمونه‌ها:

| موضوع | منبع | آنچه برداشته شد |
|---|---|---|
| Veo 3.1 | جدول قیمت Google Cloud | دلار برای هر ثانیه، با صدا: ۷۲۰p و ۱۰۸۰p ‏0.40، ‏4K ‏0.60؛ Fast و Lite ارزان‌تر؛ کلیپ ۴، ۶ یا ۸ ثانیه؛ ۲۴ فریم |
| Gemini Omni 1.2 Flash | صفحه‌ی قیمت Gemini API | ۱۲ دلار برای یک میلیون توکن خروجی ویدیو؛ ۵٬۷۹۲ توکن برای هر ثانیه‌ی ۷۲۰p، یعنی حدود ۰٫۰۷ دلار |
| Runway | صفحه‌ی قیمت Runway | Standard ماهانه ۱۵ دلار با ۶۲۵ اعتبار؛ Gen-4.5 دوازده اعتبار در ثانیه |
| Luma | صفحه‌ی قیمت Luma | Plus ماهانه ۳۰ دلار با ۱۰٬۰۰۰ اعتبار؛ ۱۰۰ اعتبار برای ۵ ثانیه |
| Kling و Sora | صفحه‌های رسمی | Kling رایگان بی اعتبار ماهانه؛ پایان برنامه‌ی Sora در ۲۶ آوریل ۲۰۲۶ و API آن در ۲۴ سپتامبر ۲۰۲۶ |

قیمت‌ها زود عوض می‌شوند؛ مقاله تاریخ خواندن (۲۱ آبان ۱۴۰۵، ۱۲ نوامبر ۲۰۲۶) را در متن و زیر جدول نوشته است.
