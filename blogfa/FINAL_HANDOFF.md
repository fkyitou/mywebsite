# تحویل نهایی آینده‌نگار

**وضعیت در یک جمله:** وبلاگ `https://ayandehnegar.blogfa.com/` منتشر شده و از بیرون باز می‌شود، با قالب آینده‌نگار (کیت ۴)، ده مقاله، هفت دسته و صفحه‌ی «درباره»، و شش اشکالی که بررسی بیرونی پیدا کرده بود روی خود وبلاگ رفع شده‌اند. بررسی کامل همه‌ی صفحه‌ها هر ده مقاله را درست نشان داد و سه ایراد کوچک پیدا کرد. کیت ۶ آماده و آزموده است: آن سه را رفع می‌کند و رفع کیت ۵ (کش آمدن تصویرها وقتی CSS از نشانی پشتیبان دیر می‌رسد) را هم دارد، ولی تا ۵ نوامبر ۲۰۲۶، ۰۸:۴۶ به وقت جهانی، جای‌گذاری نشده بود.

طراحی، مدیریت و نویسندگی: امیرحسین همتی

## از کجا شروع کنم

1. `kit.html` را در مرورگر رایانه باز کنید. بالای آن باید «نسخه‌ی ۶ کیت» را ببینید. وبلاگ از پیش ساخته شده است، پس فقط گام ۲ (قالب) لازم است، با هر سه تکه. کیت هفت گام دارد و هر چیزی که باید در بلاگفا جای‌گذاری شود، دکمه‌ی کپی دارد. پیشرفت با تیک زدن گام‌ها در همان مرورگر ذخیره می‌شود.
2. اگر جایی گیر کردید، [راهنمای نصب](docs/01-install-guide.md) و بخش عیب‌یابی آن.
3. پس از جای‌گذاری، صفحه‌های `https://ayandehnegar.blogfa.com/` از بیرون دوباره بررسی می‌شوند. صفحه‌ی اول و یک مقاله را خودتان روی گوشی و رایانه هم ببینید، چون ظاهر سربرگ، کره و تصویر بالای مقاله‌ها از بیرون سنجیدنی نیست. نشانی پنل مدیریت یا صفحه‌ی ثبت‌نام جای نشانی عمومی را نمی‌گیرد.

رمز عبور، ایمیل و کد امنیتی را فقط خودتان در سایت بلاگفا وارد کنید و برای هیچ‌کس، از جمله دستیار هوش مصنوعی، نفرستید.

## محتوای بسته

| مسیر | چیست |
|---|---|
| `kit.html` | کیت نصب: هفت گام، دکمه‌های کپی، تیک پیشرفت؛ بدون اینترنت هم باز می‌شود |
| `dist/split-cdn/` | قالب در سه تکه برای سه زبانه‌ی ویرایش قالب (راه اصلی)، حدود ۲۴، ۱۱ و ۱۲ کیلوبایت |
| `dist/split-cdn-lite/` | همان سه تکه بدون کره‌ی زمین سه‌بعدی، برای دستگاه‌های کم‌توان |
| `dist/template-cdn.html`، `dist/template-cdn-lite.html` | کل قالب یک‌جا (روش دوم)، حدود ۴۸ کیلوبایت |
| `dist/cdn/` | شش فایل CSS و JavaScript که jsDelivr از commit `3033d7c` مخزن GitHub می‌دهد؛ جای‌گذاری نمی‌شوند |
| `dist/split/`، `dist/split-lite/`، `dist/template.html`، `dist/template-lite.html` | همان قالب با CSS و JavaScript درون‌خطی، فقط برای پیش‌نمایش و آزمون‌ها؛ برای بلاگفا بیش از اندازه بزرگ‌اند |
| `posts/` | ده مقاله، هر کدام با عنوان، مقدمه، تیترها، مثال، تصویر سرصفحه، نمودار، آزمایشگاه زنده، جمع‌بندی و منابع |
| `pages/about.html` | متن صفحه‌ی «درباره‌ی آینده‌نگار» |
| `assets/` | لوگو (SVG و PNG)، ده تصویر سرصفحه‌ی ۱۶۰۰×۱۰۰۰ و یازده کارت اشتراک ۱۲۰۰×۶۳۰ |
| `preview/` | پیش‌نمایش کامل وبلاگ با ده مقاله، بدون اینترنت؛ `preview/index.html` را باز کنید |
| `docs/` | راهنماها و گزارش‌ها به دو شکل Markdown و HTML (`docs/html/`) |
| `PROJECT_STATUS.md`، `DEVELOPMENT_ROADMAP.md`، `CHANGELOG.md`، `DECISION_LOG.md`، `TEST_REPORT.md`، `FINAL_HANDOFF.md` | اسناد وضعیت، نقشه‌ی راه، تغییرات، تصمیم‌ها، آزمون و همین تحویل |
| `src/`، `tools/`، `package.json` | کد منبع قالب و ابزارهای ساخت و آزمون |
| `quality/` | نتیجه‌ی ماشینی آزمون‌ها |

کره‌ی زمین سه‌بعدی و آسمان پرستاره با WebGL و SVG در مرورگر ساخته می‌شوند و داده‌ی نقشه‌شان داخل فایل JavaScript قالب است؛ فایل سه‌بعدی جداگانه‌ای لازم نیست.

## محدودیت‌های شناخته‌شده

- سقف اندازه‌ی قالب در بلاگفا اعلام نشده است. تکه‌های ۳۰۹ و ۲۵۳ کیلوبایتی رد و تکه‌های حدود ۲۵، ۱۰ و ۱۲ کیلوبایتی کیت ۲ و تکه‌های هم‌اندازه‌ی کیت ۴ پذیرفته شدند؛ تکه‌های کیت ۵ و ۶ هم‌اندازه‌ی کیت ۴اند.
- CSS و JavaScript قالب از jsDelivr می‌آیند، با سه نشانی پشتیبان و کد یکپارچگی. اگر هر چهار نشانی از دسترس بازدیدکننده‌ای خارج باشند، او صفحه را بی‌رنگ ولی خوانا می‌بیند. اگر نشانی اصلی شکست بخورد، صفحه پس از رسیدن CSS از نشانی پشتیبان چیده می‌شود ([تصمیم ۴۲](DECISION_LOG.md)). commitهای `84deb38` (کیت ۲)، `f490e61` (کیت ۳)، `2a42eb3` (کیت ۴)، `23d29aa` (کیت ۵) و `3033d7c` (کیت ۶) باید در GitHub بمانند ([تصمیم ۴۰](DECISION_LOG.md)).
- مقاله‌های وبلاگ زنده اثری از ویرایشگر مطلب ندارند. ویرایشگر «صفحات جداگانه» ولی هر خط کد صفحه را به شکست خط تبدیل می‌کند؛ قالب از کیت ۴ این را جبران می‌کند و صفحه‌ی «درباره»ی وبلاگ زنده حالا شکست خط اضافه ندارد ([تصمیم ۴۱](DECISION_LOG.md)).
- بلاگفا روی وبلاگ‌های رایگان تبلیغ نشان می‌دهد. قالب آن را پنهان نمی‌کند، چون پنهان کردن تبلیغ خلاف قوانین بلاگفاست؛ از کیت ۳ فقط زیر پانویس هم‌اندازه‌ی نوار تبلیغ جا می‌گذارد تا نوار روی متن نیفتد.
- بلاگفا میزبانی فایل و پایگاه داده‌ی اختصاصی ندارد؛ هیچ امکانی از قالب به Backend جداگانه وابسته نیست.
