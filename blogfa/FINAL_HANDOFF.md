# تحویل نهایی آینده‌نگار

**وضعیت در یک جمله:** «فایل آماده» کامل و آزموده است و نسخه‌ی ۲ کیت تکه‌های کم‌حجمی دارد که برای سقف اندازه‌ی بلاگفا ساخته شده‌اند؛ وبلاگ `https://ayandehnegar.blogfa.com/` ساخته شده و از بیرون باز می‌شود، ولی هنوز قالب دیگری (GAME ZONE) رویش است، پس «قالب نصب‌شده» و «وبلاگ منتشرشده و آنلاین» هنوز انجام نشده‌اند.

طراحی، مدیریت و نویسندگی: امیرحسین همتی

## از کجا شروع کنم

1. `kit.html` را در مرورگر رایانه باز کنید. بالای آن باید «نسخه‌ی ۲ کیت» را ببینید؛ تکه‌های کیت قبلی را بلاگفا نمی‌پذیرد. هفت گام دارد و هر چیزی که باید در بلاگفا جای‌گذاری شود، دکمه‌ی کپی دارد. پیشرفت با تیک زدن گام‌ها در همان مرورگر ذخیره می‌شود.
2. اگر جایی گیر کردید، [راهنمای نصب](docs/01-install-guide.md) و بخش عیب‌یابی آن.
3. پس از انتشار، نشانی عمومی وبلاگ (مثل `https://ayandehnegar.blogfa.com/`) را بفرستید تا صفحه‌ها از بیرون بررسی شوند. نشانی پنل مدیریت یا صفحه‌ی ثبت‌نام جای آن را نمی‌گیرد.

رمز عبور، ایمیل و کد امنیتی را فقط خودتان در سایت بلاگفا وارد کنید و برای هیچ‌کس، از جمله دستیار هوش مصنوعی، نفرستید.

## محتوای بسته

| مسیر | چیست |
|---|---|
| `kit.html` | کیت نصب: هفت گام، دکمه‌های کپی، تیک پیشرفت؛ بدون اینترنت هم باز می‌شود |
| `dist/split-cdn/` | قالب در سه تکه برای سه زبانه‌ی ویرایش قالب (راه اصلی)، حدود ۲۵، ۱۰ و ۱۲ کیلوبایت |
| `dist/split-cdn-lite/` | همان سه تکه بدون کره‌ی زمین سه‌بعدی، برای دستگاه‌های کم‌توان |
| `dist/template-cdn.html`، `dist/template-cdn-lite.html` | کل قالب یک‌جا (روش دوم)، حدود ۴۷ کیلوبایت |
| `dist/cdn/` | شش فایل CSS و JavaScript که jsDelivr از commit `84deb38` مخزن GitHub می‌دهد؛ جای‌گذاری نمی‌شوند |
| `dist/split/`، `dist/split-lite/`، `dist/template.html`، `dist/template-lite.html` | همان قالب با CSS و JavaScript درون‌خطی، فقط برای پیش‌نمایش و آزمون‌ها؛ برای بلاگفا بیش از اندازه بزرگ‌اند |
| `posts/` | ده مقاله، هر کدام با عنوان، مقدمه، تیترها، مثال، تصویر سرصفحه، نمودار، آزمایشگاه زنده، جمع‌بندی و منابع |
| `pages/about.html` | متن صفحه‌ی «درباره‌ی آینده‌نگار» |
| `assets/` | لوگو (SVG و PNG)، ده تصویر سرصفحه‌ی ۱۶۰۰×۱۰۰۰ و یازده کارت اشتراک ۱۲۰۰×۶۳۰ |
| `preview/` | پیش‌نمایش کامل وبلاگ با ده مقاله، بدون اینترنت؛ `preview/index.html` را باز کنید |
| `docs/` | راهنماها و گزارش‌ها به دو شکل Markdown و HTML (`docs/html/`) |
| `PROJECT_STATUS.md`، `DEVELOPMENT_ROADMAP.md`، `CHANGELOG.md`، `DECISION_LOG.md`، `TEST_REPORT.md`، `FINAL_HANDOFF.md` | اسناد وضعیت، نقشه‌ی راه، تغییرات، تصمیم‌ها، آزمون و همین تحویل |
| `src/`، `tools/`، `package.json` | کد منبع قالب و ابزارهای ساخت و آزمون |
| `quality/` | نتیجه‌ی ماشینی آزمون‌ها |

کره‌ی زمین سه‌بعدی و آسمان پرستاره با WebGL و SVG در مرورگر ساخته می‌شوند و داده‌ی نقشه‌شان داخل فایل JavaScript قالب است؛ فایل سه‌بعدی جداگانه‌ای لازم نیست.

| کار | وضعیت |

| تطبیق کیت و راهنماها با پنل واقعی بلاگفا | ✅ با تصویرهای پنل (۴ نوامبر ۲۰۲۶) |
| ساخت حساب و وبلاگ در بلاگفا | ✅ صاحب وبلاگ؛ `https://ayandehnegar.blogfa.com/` از بیرون با عنوان «آینده‌نگار» باز شد (۴ نوامبر ۲۰۲۶، حدود ۲۱:۵۰ به وقت جهانی) |
| نخستین تلاش نصب قالب | ❌ بلاگفا تکه‌های ۳۰۹ و ۲۵۳ کیلوبایتی را با پیام «حجم قالب بسیار بالا است» رد کرد |
| ساخت تکه‌های کم‌حجم (نسخه‌ی ۲ کیت) | ✅ ساخته و آزموده روی پیش‌نمایش؛ فایل‌های jsDelivr با commit روی GitHub بایت‌به‌بایت یکی‌اند |
| نصب قالب | ⬜ با صاحب وبلاگ، با نسخه‌ی ۲ کیت |
| انتشار ده مقاله و صفحه‌ی درباره | ⬜ با صاحب وبلاگ |
| بررسی وبلاگ منتشرشده از بیرون | ⬜ پس از رسیدن نشانی عمومی |

## محدودیت‌های شناخته‌شده

- سقف اندازه‌ی قالب در بلاگفا اعلام نشده است. تکه‌های ۳۰۹ و ۲۵۳ کیلوبایتی رد شدند؛ تکه‌های نسخه‌ی ۲ (بزرگ‌ترینشان حدود ۲۵ کیلوبایت) هنوز روی خود بلاگفا ذخیره نشده‌اند.
- CSS و JavaScript قالب از jsDelivr می‌آیند، با سه نشانی پشتیبان و کد یکپارچگی. اگر هر چهار نشانی از دسترس بازدیدکننده‌ای خارج باشند، او صفحه را بی‌رنگ ولی خوانا می‌بیند. commit `84deb38` باید در GitHub بماند ([تصمیم ۴۰](DECISION_LOG.md)).
- رفتار ویرایشگر مطلب با کلاس‌ها و ویژگی‌های `data-` فقط روی خود بلاگفا آزمودنی است. راه بررسی در راهنمای نصب آمده است.
- بلاگفا روی وبلاگ‌های رایگان تبلیغ نشان می‌دهد. قالب آن را پنهان نمی‌کند، چون پنهان کردن تبلیغ خلاف قوانین بلاگفاست.
- بلاگفا میزبانی فایل و پایگاه داده‌ی اختصاصی ندارد؛ هیچ امکانی از قالب به Backend جداگانه وابسته نیست.
