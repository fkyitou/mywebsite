# معماری

آینده‌نگار روی بلاگفا میزبانی می‌شود: نه سرور و نه پایگاه داده‌ای از خود دارد. همه‌ی کار در مرورگر خواننده انجام می‌شود، از سه تکه‌ی قالب بلاگفا و فایل‌هایی که از یک commit قفل‌شده روی jsDelivr می‌آیند. آخرین به‌روزرسانی: ۲۳ آبان ۱۴۰۵ (۱۴ نوامبر ۲۰۲۶).

## نمای کلی

```
مخزن (blogfa/src، posts، pages)
   │  node tools/build.mjs
   ▼
dist/                         dist/cdn/ (نام هر فایل با هش محتوا)
 ├ template-cdn.html  ──►  سه تکه در «ویرایش قالب» بلاگفا
 ├ split-cdn/1،2،3            │ بار با <script integrity> از
 └ box.html  ──►  کادر «کدهای اختصاصی»      │ cdn.jsdelivr / fastly / gcore / rawcdn.githack
                                   ▼
                         مرورگر خواننده (localStorage فقط برای انتخاب‌های خودش)
```

## سه تکه‌ی قالب

بلاگفا قالب را در سه زبانه می‌گیرد: «صفحات اصلی» (`<blog:PostTemplate>`، صفحه‌ی اول، مقاله‌ها، موضوع‌ها، برچسب‌ها)، «آرشیو» (`<blog:ArchiveTemplate>`) و «صفحات جداگانه» (`<blog:PageTemplate>`، مثل «درباره» و `bmc`). منبع هر سه در `src/template.html` است و تکه‌های مشترک در `src/partials/`. بلاگفا تکه‌ی خیلی بزرگ را نمی‌پذیرد (۳۰۹ و ۲۵۳ کیلوبایت رد شد)، پس نسخه‌ی CDN فقط HTML و یک بارگذار کوچک (`src/js/loader.js`) دارد و بقیه را از jsDelivr می‌گیرد.

## کد کادر اختصاصی (ابزار خواننده)

`dist/box.html` (حدود ۲ کیلوبایت) یک خط تنظیم `window.AN_X_OPT` و بارگذار `src/addons/box.js` دارد که `an-addons.*.js` و `.css` را با SRI و چهار نشانی پشتیبان می‌آورد. سه فایل فقط با فشار دکمه بار می‌شوند، همه با SRI: `an-qr` (کد QR)، `an-guide` («نگار») و `an-teaser` (فیلم معرفی). نشانی و هش آن‌ها هنگام ساخت جای `'@QR@'`، `'@GUIDE@'` و `'@TEASER@'` در `addons.js` می‌نشیند. صاحب وبلاگ هر ابزار را با ۰ کردن عددش در `AN_X_OPT` خاموش می‌کند.

## فیلم معرفی

`src/addons/teaser.js` دو بخش دارد: `AN_TEASER.film` (کشیدن هر لحظه روی بوم ۱۹۲۰×۱۰۸۰ با مولد تصادفی دانه‌دار، و موسیقی با Web Audio) و پخش‌کننده. همان `draw()` و `score()` را `tools/teaser.mjs` قاب‌به‌قاب در Playwright اجرا می‌کند، صدا را با `OfflineAudioContext` می‌سازد و ffmpeg آن‌ها را MP4 می‌کند. پس فیلم روی وبلاگ و فایل MP4 یک منبع دارند.

## ساخت، انتشار و آزمون

| ابزار | کار |
|---|---|
| `tools/build.mjs` | ساختن همه‌ی نسخه‌ها؛ الگوهای ممنوع را می‌گیرد؛ قالب CDN را فقط وقتی می‌نویسد که commit `cdn.json` همه‌ی فایل‌ها را داشته باشد و push شده باشد |
| `tools/preview.mjs` | پیش‌نمایش محلی با محتوای واقعی مقاله‌ها |
| `tools/kit.mjs` | `kit.html`، کیت نصب گام‌به‌گام با دکمه‌ی کپی |
| `tools/check.mjs`، `validate.mjs`، `a11y.mjs`، `interact.mjs`، `behaviour.mjs`، `toolkit.mjs`، `links.mjs`، `cdntest.mjs`، `kittest.mjs` | آزمون‌ها ([گزارش کنترل کیفیت](QA_REPORT.md))؛ `npm run qa` همه را پشت هم اجرا می‌کند |
| `tools/astro.mjs` | فرمول‌های مرجع نجومی برای آزمون آسمان |
| `tools/teaser.mjs` | ساخت MP4، پوستر، برگه‌ی تماس، زیرنویس و اندازه‌گیری صدا |

انتشار سه commit دارد: (A) منبع‌ها و `dist/cdn`، (B) قفل `cdn.json` روی A با قالب‌ها و کیت، (C) گزارش آزمون. هر commit قفل‌شده باید بماند، چون قالب نصب‌شده فایل‌هایش را از همان‌جا می‌گیرد ([راهنمای بازگشت](ROLLBACK_GUIDE.md)).
