# وضعیت پروژه و نقشه‌ی راه

این سند زنده است: هر کس کار را ادامه می‌دهد، اول این را می‌خواند و در پایان کارش به‌روزش می‌کند. آخرین به‌روزرسانی: ۱۳ آبان ۱۴۰۵ (۴ نوامبر ۲۰۲۶).

## وضعیت فعلی

| مرحله | وضعیت |

| وبلاگ منتشرشده | انجام نشده؛ با حساب صاحب وبلاگ |

## ایده‌ها برای آینده

- کامپایل موازی شیدرهای کره با افزونه‌ی `KHR_parallel_shader_compile`، تا آماده شدن کره صفحه را نگه ندارد.
- تصویر پیش‌نمایش کره (یک فریم ثابت) پیش از آماده شدن WebGL.
- حالت «ارائه در کلاس»: بزرگ‌تر شدن متن و نمودارها برای ویدئوپروژکتور.
- واژه‌نامه‌ی جمعی همه‌ی مقاله‌ها در یک صفحه.

**ناشدنی روی بلاگفا** (ثبت شده تا دوباره بررسی نشود): سرویس‌ورکر و حالت آفلاین، چون بلاگفا میزبانی فایل ندارد؛ پایگاه داده یا Backend اختصاصی؛ آمار بازدید اختصاصی بدون سرویس بیرونی.

## آزمایش‌های ناموفق و درس‌هایشان

| آزمایش | نتیجه | درس |
|---|---|---|
| کشیدن ستاره‌ها روی بوم و تبدیل با `toBlob` | روی کارت گرافیک نرم‌افزاری صفحه را چند ثانیه نگه داشت | هر خواندن از کارت گرافیک صفحه را منتظر می‌گذارد؛ SVG جایگزین شد |
| جای خالی بنر مقاله با `margin-top` | حاشیه از بدنه بیرون زد و جابه‌جایی کم نشد | جای خالی باید یک جعبه‌ی واقعی هم‌اندازه باشد؛ جعبه‌ی خالی تیتر صفحه همین کار را کرد |
| جای خالی با `padding-top` روی فهرست مطالب | مرورگر جابه‌جایی جعبه‌ی فهرست را باز هم شمرد | همان درس |
| پیدا کردن هزینه‌ی گرافیکی صفحه با خاموش کردن تک‌تک افکت‌ها (blur، شیشه‌ی مات، آسمان، سایه، ماسک، `will-change`) | هیچ افکتی به‌تنهایی هزینه را توضیح نداد؛ حتی با خاموش کردن همه، صفحه‌ی آرشیو حدود ۲٫۶ ثانیه کار گرافیکی داشت، در برابر ۰٫۱ ثانیه برای یک صفحه‌ی ساده | هزینه از نقاشی خود صفحه با کارت گرافیک نرم‌افزاری است، نه یک افکت؛ نتیجه‌ی کارایی این محیط بدبینانه است |
| حالت ثابت کره برای بهتر شدن امتیاز Lighthouse | امتیاز بارگذاری تغییری بیش از نوسان عادی نکرد | Lighthouse فقط بارگذاری را می‌سنجد؛ سود این تغییر در روانی پس از بارگذاری است (۱۷ فریم در ۵ ثانیه به ۱۵۵ تا ۱۸۵) |
| پیمایش نرم در آزمون تصویرهای کارت‌ها | آزمون هرگز به پایین صفحه نمی‌رسید | آزمون‌ها با پیمایش فوری، و برای پیمایش‌های واقعی با انتظار تا ایستادن صفحه |

## کارهای انجام‌شده در این دور

ممیزی کامل و ۱۴ یافته ([گزارش ممیزی](09-audit-report.md))، آسمان سراسری، صداگذاری، رفع پرش صفحه‌ها، اعتبارسنجی W3C، آزمون‌های تعامل و پیوند و مقایسه‌ی تصویری، حالت ثابت کره روی دستگاه کند، راهنماهای HTML، ماتریس ردیابی و گزارش نهایی. دلیل هر تصمیم در [دفتر تصمیم‌ها](05-decision-log.md)، بندهای ۲۲ تا ۳۳.

## ادامه دادن کار

```bash
cd blogfa
npm install
npm run qa                    # ساخت، پیش‌نمایش و همه‌ی آزمون‌ها
node tools/visual.mjs         # مقایسه‌ی تصویری با مرجع؛ پس از تغییر عمدی ظاهر: --update
node tools/docs.mjs           # ساخت HTML راهنماها
node tools/kit.mjs            # ساخت کیت نصب
```

آزمون‌های مرورگر به Playwright نیاز دارند. اگر Playwright جهانی نصب شده است، فرمان‌ها را با `NODE_PATH=$(npm root -g)` اجرا کنید.

**قاعده‌ی کیفیت:** هر تغییری که یک آزمون را رد کند یا تصویر مرجع را بی‌دلیل عوض کند، اصلاح یا برگردانده می‌شود. فقط کامیتی که همه‌ی آزمون‌ها رویش گذشته‌اند «آخرین نسخه‌ی سالم» این سند می‌شود.
