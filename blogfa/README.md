# آینده‌نگار — روایت انسان، ایده و فناوری

قالب اختصاصی، ده مقاله و کیت نصب یک وبلاگ بلاگفا، برای درس «تجارت الکترونیک و امنیت شبکه»، پایه‌ی دوازدهم رشته‌ی شبکه و نرم‌افزار رایانه.

طراحی، مدیریت و نویسندگی: امیرحسین همتی

- **برای نصب:** `kit.html` را در مرورگر باز کنید (بالای آن «نسخه‌ی ۷ کیت» آمده است). تکه‌های قالب حدود ۲۵، ۱۲ و ۱۳ کیلوبایت‌اند و CSS، JavaScript، قلم و تصویر پیش‌نمایش پیوند قالب از jsDelivr می‌آیند.
- **برای دیدن نتیجه بدون اینترنت:** `preview/index.html`.
- **وضعیت و تحویل:** [FINAL_HANDOFF.md](FINAL_HANDOFF.md) و [PROJECT_STATUS.md](PROJECT_STATUS.md).

وبلاگ `https://ayandehnegar.blogfa.com/` منتشر شده و از بیرون باز می‌شود (۵ نوامبر ۲۰۲۶): قالب آینده‌نگار با کیت ۴، ده مقاله، هفت دسته و صفحه‌ی «درباره». بررسی کامل همه‌ی صفحه‌ها هر ده مقاله را درست نشان داد. کیت ۷ آماده است: حالت «ارائه در کلاس» برای نشان دادن مقاله‌ها روی ویدئوپروژکتور، توضیح کامل وبلاگ در پانویس (بلاگفا فقط ۱۰۰ نویسه‌ی «شرح خلاصه» را نگه می‌دارد)، تصویر پیش‌نمایش پیوند در پیام‌رسان‌ها، قلم از همان میزبان فایل‌های قالب، و رفع‌های کیت‌های ۵ و ۶ (ساعت، یک برچسب، عنوان آرشیو ماه و کش آمدن تصویرها وقتی CSS از نشانی پشتیبان دیر می‌رسد). تا آخرین بررسی (حدود ۱۷:۲۰ به وقت جهانی) کیت ۴ روی وبلاگ بود.
