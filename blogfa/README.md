# آینده‌نگار — روایت انسان، ایده و فناوری

قالب اختصاصی، ده مقاله و کیت نصب یک وبلاگ بلاگفا، برای درس «تجارت الکترونیک و امنیت شبکه»، پایه‌ی دوازدهم رشته‌ی شبکه و نرم‌افزار رایانه.

طراحی، مدیریت و نویسندگی: امیرحسین همتی

- **برای نصب:** `kit.html` را در مرورگر باز کنید (بالای آن «نسخه‌ی ۶ کیت» آمده است). تکه‌های قالب حدود ۲۴، ۱۱ و ۱۲ کیلوبایت‌اند و CSS و JavaScript قالب از jsDelivr می‌آیند.
- **برای دیدن نتیجه بدون اینترنت:** `preview/index.html`.
- **وضعیت و تحویل:** [FINAL_HANDOFF.md](FINAL_HANDOFF.md) و [PROJECT_STATUS.md](PROJECT_STATUS.md).

وبلاگ `https://ayandehnegar.blogfa.com/` منتشر شده و از بیرون باز می‌شود (۵ نوامبر ۲۰۲۶): قالب آینده‌نگار با کیت ۴، ده مقاله، هفت دسته و صفحه‌ی «درباره». بررسی کامل همه‌ی صفحه‌ها هر ده مقاله را درست نشان داد. کیت ۶ آماده است: سه ایراد کوچکی که آن بررسی پیدا کرد (ساعت، یک برچسب و عنوان آرشیو ماه) و کش آمدن تصویرها وقتی CSS از نشانی پشتیبان دیر می‌رسد را رفع می‌کند؛ تا ۰۸:۴۶ به وقت جهانی جای‌گذاری نشده بود.
